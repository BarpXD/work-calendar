
# Рабочий календарь — Android / Python

Стек:
- Python
- Kivy
- SQLite
- Buildozer + python-for-android для APK

## Запуск на ПК

Windows:
```powershell
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

## Логика

- Все дни по умолчанию красные — выходные.
- Через `+ Смена` можно создать смену: название, начало, конец, цвет.
- Выбираешь маркер сверху и нажимаешь день.
- В день сохраняются часы, зарплата и ставка на момент назначения.
- Изменение ставки в настройках не меняет старые дни.
- `⚙` содержит ставку и правила начисления зарплаты.
- Правила начисления пока только хранятся как настройки: автоматическая выплата не выполняется.
